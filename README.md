# LG TV Cast

Android app for casting local video files or direct video URLs to compatible LG Smart TVs on the same Wi-Fi network using DLNA/UPnP.

## Important
This is **media casting**, not full phone-screen mirroring. Full screen mirroring depends on the phone and LG TV supporting Miracast/Wi-Fi Display.

## Build
- Android Studio or Codemagic
- Android SDK 35
- JDK 17

The project uses Android Gradle Plugin 8.7.3 and Gradle 8.9. Android API 35 requires AGP 8.6.0 or newer. 

## Use
1. Connect phone and TV to the same Wi-Fi network.
2. Open LG TV Cast.
3. Tap Scan TVs.
4. Select the TV.
5. Paste a direct video URL, or choose a video from the phone.
6. Tap Cast.
7. Use Play/Pause/Stop controls.

Some LG models may expose DLNA only when media sharing is enabled.
